生成日期：2026-10-22　|　记录总数：530 条

## 1. 这是什么

把两部曲的核心设定拆成可检索、可筛选、可二次加工的结构化数据，输出三种等价形态：

- `csv/`：18 张表，UTF-8 with BOM，Excel/WPS 可直接打开
- `lotm_setting.json`：同一份数据的 JSON 包，便于程序读取
- `lotm_setting.sqlite`：SQLite 数据库，便于 SQL 查询与联表

本版目标是**骨架完整、来源可追**：22 条途径、220 个序列、五纪元、国家/地理、正神教会与主要隐秘组织、核心人物、封印物、术语、语言货币、衍生作品与来源表。

## 4. 关键字段约定

- **途径ID**：P01—P22，全库统一外键；`sequences.途径ID` 可关联 `pathways.途径ID`
- **序列**：0—9，其中 9 最低、0 为真神
- **层级**：低序列（9—8）、中序列（7—5）、圣者（4—3）、天使（2—1）、真神（0）
- **源质**：E01—E09，对应 9 大源质
- **置信度**：A = 官方设定资料/原文可直证；B = 官方资料站或粉丝维基；C = 二手整理或待核
- **来源**：对应 `sources.来源ID`，可回溯 URL

## 5. 使用示例

SQLite：

```sql
-- 查某条途径的全部序列
SELECT 序列, 名称, 层级 FROM sequences WHERE 途径 = '愚者' ORDER BY CAST(序列 AS INTEGER) DESC;

-- 查某组织成员
SELECT 姓名, 途径, 序列 FROM characters WHERE 所属组织 LIKE '%塔罗会%';

-- 查 22 条途径与源质（列名为“途径（序列0）”，需加引号）
SELECT "途径（序列0）", "序列9", 源质, 对应旧日 FROM pathways ORDER BY 途径ID;
```

Python：

```python
import sqlite3, pandas as pd
con = sqlite3.connect("lotm_setting.sqlite")
df = pd.read_sql("SELECT * FROM sequences", con)
print(df.groupby("层级").size())
```

## 6. 覆盖边界（重要）

1. **220/220 序列名称已完整收录**，但**每个序列的能力细节、魔药配方、仪式步骤尚未逐条展开**。这部分必须回到原文逐章抽取，网络二手资料错误率高，本版不做猜测。
2. **人物表是“核心人物”而非全量**。两部曲有名有姓的角色数以千计，v1 收录 47 位与主线强相关者。
3. **《宿命之环》覆盖度低于第一部**：其新增设定、外神关系、结局细节仍需系统回查原文；相关条目标注 B/C 置信度。
4. **封印物仅收录有明确编号或强关联者**，未做全量编号表。
5. 纪元年份来自粉丝维基整理，不同版本可能存在差异；冲突时以原文叙述为准。
6. 本库是**设定索引**，不是原文替代品；版权归原作者与权利方所有，仅供研究、二创与跑团参考。
